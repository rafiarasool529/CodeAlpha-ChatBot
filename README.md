# CodeAlpha Basic Chatbot

## Project Description
This is a simple rule-based chatbot developed using Python as part of the CodeAlpha Python Programming Internship.

The chatbot interacts with users through text input and provides predefined responses based on user messages.

## Features
- Simple text-based interface.
- Greets users with predefined messages.
- Responds to "hello" and "how are you".
- Provides responses using conditional statements.
- Supports goodbye messages.
- Runs continuously until the user exits.

## Technologies Used
- Python
- If-Else Statements
- Functions
- While Loop
- User Input and Output
- Strings

## How to Use
1. Run the Python program.
2. Enter a message such as "hello".
3. The chatbot responds with a predefined reply.
4. Try different messages.
5. Type "bye" to end the conversation.

## Sample Conversation

User: hello

Chatbot: Hi!

User: how are you?

Chatbot: I'm fine, thanks!

User: bye

Chatbot: Goodbye!

## How to Run
1. Download the Python source code.
2. Open the file in Python or Google Colab.
3. Run the program.
4. Start chatting with the chatbot.

## Project Purpose
The purpose of this project is to practice Python fundamentals, including functions, loops, conditional statements, strings, and user input/output.
